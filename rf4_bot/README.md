RF4 Community Bot (Telegram)

Профессиональный Telegram-бот для автоматизации, модерации и координации игроков сообщества по игре Русская Рыбалка 4 (РР4).
Бот работает в реальном времени и обслуживает живое игровое сообщество.

## Основные возможности
* Интерактивная модерация: Автоматическое обнаружение спама, рекламы и ненормативной лексики с системой прогрессивных наказаний.
* Конструктор постов (Предложить пост): Удобный пошаговый мастер (FSM) для публикации трофеев, фарм-точек и параметров ловли.
* Система подтверждения админом: Отправка готовых отчетов в закрытый чат модераторов с кнопкой быстрой публикации в новостной канал.
* Встроенный веб-сервер: Легковесный aiohttp сервер для поддержки 24/7 аптайма на облачном хостинге.

## Технологии и стек
* Язык: Python 3.10+
* Фреймворк: aiogram (асинхронный фреймворк для Telegram Bot API)
* Сеть и веб: aiohttp, встроенный HTTP-сервер для пинга
* Архитектура состояний: FSMContext (FSM в памяти)
* Хостинг: Render (Cloud Web Service) + UptimeRobot (мониторинг 24/7)

## Безопасность (Production Ready)
Проект разработан с соблюдением стандартов безопасности:
* Все конфиденциальные данные (токены, списки модерации) вынесены из исходного кода и управляются через переменные окружения (Environment Variables).
* Исходный код полностью открыт для ревью и портфолио.
